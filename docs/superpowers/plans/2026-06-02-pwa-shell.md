# PWA Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Rojin client an installable PWA — manifest + service worker (app-shell cache, never `/api` or `/socket.io`) + a branded chat-bubble icon — verified on a localhost production build.

**Architecture:** Use `@angular/pwa` (ngsw) with the existing webpack browser builder. Author one chat-bubble SVG, rasterize to PNGs with `sharp`. Customize the manifest (Rojin, charcoal theme) and `ngsw-config.json` (cache shell only). Add iOS/manifest meta to `index.html`.

**Tech Stack:** Angular 21, `@angular/service-worker` (ngsw), `sharp` (dev), web app manifest.

**Verification model:** No unit tests apply. Gate = `npm run build` GREEN per task; final = a localhost production-build check (Chrome DevTools → Application: manifest installable, `ngsw-worker.js` active, offline shell loads, `/api` not cached). `npm test` remains the broken scaffold; not used.

**Spec:** `docs/superpowers/specs/2026-06-02-pwa-shell-design.md`
**Branch:** `feature/pwa-shell` (created; spec committed).

### Task 1: Add @angular/pwa and customize manifest + ngsw config

**Files:** Modify (via `ng add`) `client/angular.json`, `client/package.json`, `client/src/app/app.module.ts`; Create/replace `client/src/manifest.webmanifest`, `client/ngsw-config.json`

- [ ] **Step 1:** From `client/`, run: `npx ng add @angular/pwa --skip-confirmation --project client`
  (If the project name differs, run `npx ng add @angular/pwa --skip-confirmation` and accept the default project.) This adds `@angular/service-worker`, sets `serviceWorker: true` + `ngswConfigPath` on the production build target in `angular.json`, adds `manifest.webmanifest` to assets, registers `ServiceWorkerModule` in `app.module.ts`, and scaffolds default icons + `ngsw-config.json`.
- [ ] **Step 2:** Verify the SW registration in `app.module.ts` reads (adjust if `ng add` used `isDevMode`):
```typescript
ServiceWorkerModule.register('ngsw-worker.js', {
  enabled: !isDevMode(),
  registrationStrategy: 'registerWhenStable:30000',
})
```
(`isDevMode` imported from `@angular/core`.)
- [ ] **Step 3:** Replace `client/src/manifest.webmanifest` with:
```json
{
  "name": "Rojin",
  "short_name": "Rojin",
  "description": "Conversations worth keeping.",
  "theme_color": "#241121",
  "background_color": "#241121",
  "display": "standalone",
  "scope": "/",
  "start_url": "/",
  "icons": [
    { "src": "assets/icons/icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any maskable" },

```
- [ ] **Step 4:** Replace `client/ngsw-config.json` with:
```json
{
  "$schema": "./node_modules/@angular/service-worker/config/schema.json",
  "index": "/index.html",
  "assetGroups": [
    {
      "name": "app",
      "installMode": "prefetch",

    }
  ]

```
(No `dataGroups` → `/api` and `/socket.io` are never cached.)
- [ ] **Step 5:** Run `npm run build` → Expected: GREEN; output includes `ngsw-worker.js` and `ngsw.json` in `dist/`.

### Task 2: Chat-bubble icon assets + index.html meta

**Files:** Create `client/src/assets/icons/icon.svg`, `client/scripts/build-icons.mjs`, `client/src/assets/icons/{icon-192,icon-512,apple-touch-icon}.png`; Modify `client/package.json` (dev `sharp`), `client/src/index.html`; delete the `ng add` default icons

- [ ] **Step 1:** Create `client/src/assets/icons/icon.svg` (charcoal bg, gold bubble + tail, aubergine serif "R"; bubble padded so it also works maskable):
```xml
<svg width="512" height="512" viewBox="0 0 512 512" xmlns="http://www.w3.org/2000/svg">
  <rect width="512" height="512" fill="#241121"/>
  <path d="M168 150 h176 a40 40 0 0 1 40 40 v100 a40 40 0 0 1 -40 40 h-120 l-58 46 v-46 h-1 a39 39 0 0 1 -39 -40 v-100 a40 40 0 0 1 40 -40 z"
        fill="#b08d57"/>
  <text x="256" y="245" font-family="Georgia, 'Times New Roman', serif" font-size="150"
        font-weight="700" fill="#3a0e3c" text-anchor="middle" dominant-baseline="middle">R</text>
</svg>
```
- [ ] **Step 2:** Add `sharp` as a dev dependency: from `client/`, `npm install --save-dev sharp`.
- [ ] **Step 3:** Create `client/scripts/build-icons.mjs`:
```javascript
import sharp from 'sharp';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import path from 'node:path';

const dir = path.dirname(fileURLToPath(import.meta.url));
const iconsDir = path.join(dir, '..', 'src', 'assets', 'icons');
const svg = readFileSync(path.join(iconsDir, 'icon.svg'));

const sizes = { 'icon-192.png': 192, 'icon-512.png': 512, 'apple-touch-icon.png': 180 };
for (const [name, size] of Object.entries(sizes)) {
  await sharp(svg, { density: 512 }).resize(size, size).png().toFile(path.join(iconsDir, name));
  console.log('wrote', name);
}
```
- [ ] **Step 4:** Run it: from `client/`, `node scripts/build-icons.mjs`. Expected: writes the 3 PNGs.
- [ ] **Step 5:** VISUALLY verify the generated `icon-512.png` (open/view it) — the gold bubble with a legible aubergine "R" on charcoal. If the "R" failed to render (font), replace the `<text>` with an outlined glyph or a heavier system serif and re-run. Delete the leftover `ng add` default icons (the Angular-logo PNGs) so only ours remain.
- [ ] **Step 6:** In `client/src/index.html` `<head>`, ensure these exist (the manifest link + theme-color may already be added by `ng add` — keep one copy):
```html
<link rel="manifest" href="manifest.webmanifest">
<meta name="theme-color" content="#241121">
<link rel="apple-touch-icon" href="assets/icons/apple-touch-icon.png">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="Rojin">
```
- [ ] **Step 7:** Run `npm run build` → GREEN; confirm the icons are copied into `dist/.../assets/icons/`.
- [ ] **Step 8: Commit** `feat(client): chat-bubble PWA icon + iOS/manifest meta`
